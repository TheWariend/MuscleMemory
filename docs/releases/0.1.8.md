# MuscleMemory 0.1.8

Python package: `thewariend-musclememory==0.1.8`.
TypeScript SDK: `@thewariend/musclememory@0.1.3`.

## Changes

- Recover usable evidence from incomplete native recordings without replaying
  actions or modifying the original recordings.
- Offer optional model curation for reusable lessons, with cited evidence and
  explicit rejection and retry states. Local learning remains the default.
- Keep skill naming separate from curation. Manual naming makes no automatic
  naming calls; users can explicitly select automatic naming in settings.
- Enforce compatible actions and the stored test command when counting later
  checks. Line proof, two later passing checks, and human approval still gate reuse.
- Show skills, recordings, and their evidence relationships in the memory graph.
- Paginate Activity across retained sessions and show whether automatic lookup
  delivered a skill, found no eligible skill, or withheld guidance. Delivery never
  counts as proof of application or a passing check.
- Return bounded MCP inspection summaries for large records, with a path to full
  authenticated details.
- Add local Codex plugin packaging with transparent branding assets, and a
  ParcelDesk example demonstrating learning, approval, and reuse.
- Update the TypeScript input contracts for memory-delivery reports.

## Upgrade

Stop the service before upgrading. Make a private backup of the database named
in the installation's `config.json` (under `~/.musclememory` by default, or
`MM_HOME`). Keep backups outside the repository. Apply schema migrations before
restarting the server; normal local initialization also applies migrations.

For a pipx installation:

```sh
musclememory stop
pipx upgrade thewariend-musclememory
musclememory migrate
musclememory start
```

Projects using the TypeScript SDK can update with:

```sh
npm install @thewariend/musclememory@0.1.3
```

Schema migration does not distill historical recordings or approve existing
skills. Historical recovery and curation are separate operations: preview their
reports before applying them. See [learning and migration](../semantic-learning.md).
No benchmark gains are claimed for this release.
